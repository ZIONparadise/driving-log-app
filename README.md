# 업무용승용차 운행기록부 자동 업데이트 앱

## 반영된 계산 규칙

1. 7번 주행거리 = 6번 주행후 계기판거리 - 5번 주행전 계기판거리
2. 8번 출퇴근용 + 9번 일반 업무용 = 7번 주행거리
3. 따라서 9번 일반 업무용 = 7번 주행거리 - 8번 출퇴근용

## 이번 버전 핵심 변경

- 7번 주행거리와 9번 일반 업무용을 고정 숫자가 아닌 엑셀 수식으로 입력
- 다운로드 후 엑셀에서 주행전거리, 주행후거리, 출퇴근용 거리를 수정하면 자동 재계산
- 논리 오류는 조건부 서식으로 빨간색 표시
- 저장 파일명 자동 생성: `업무용운행기록부_30th_홍성학_5월.xlsx`

## 빨간색 표시 규칙

- 주행후 거리가 주행전 거리보다 작으면 5번, 6번, 7번 숫자 셀을 빨간색 표시
- 출퇴근용 거리가 전체 주행거리보다 크면 7번, 8번, 9번 숫자 셀을 빨간색 표시
- 앱 미리보기 화면에서도 문제 숫자를 빨간색으로 표시

## 기타 기능
- .xls 손상/비표준 파일 대응
- 병합 셀(MergedCell) 쓰기 오류 대응
- 검산 오류가 의심되는 항목 경고 표시

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```
